Community fan tool — not affiliated with Blizzard. Gem effect values are compiled from public game guides (GameStrategyHQ, Wowhead, Game8) and may lag behind the latest balance patch. Rank 1–10 values are interpolated between published milestones for gems where only Rank 1 and Rank 10 data is publicly documented, so treat mid-rank numbers as close approximations. A few very recently added gems have no confirmed numeric tooltip anywhere yet and appear as proc-only entries. The 60-second timeline uses a fixed illustrative cadence (not rank-adjusted) for gems with a published buff duration + cooldown, assumes the effect triggers the instant it's available (a best case), and shows chance/RNG-gated procs as a hatched "available, timing not fixed" band rather than a precise schedule. The synergy summary adds percentage effects together for a quick at-a-glance total — in the actual game some bonuses combine multiplicatively rather than additively, so use this as a directional guide, not an exact damage calculator.
